# AGENTS.md

## Working Rules

- When code changes affect routes, schema, business rules, auth, UI, or module behavior, update root README.md and relevant files in docs/.
- If UI changes affect colors, layouts, dashboards, forms, or onboarding screens, update docs/ui-theme.md if it exists.
- Run relevant tests before handoff.
- Keep changes aligned with the existing framework, naming, and documentation style.
