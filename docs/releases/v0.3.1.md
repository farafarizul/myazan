# myAzan v0.3.1

Release stabil Windows x64 pada 18 November 2026. Menggantikan v0.3.0 sebagai versi disyorkan.

## Pembaikan

- Sokongan bulan JAKIM `Ogos` bersama `Ogo`. Semua 12 bulan telah disemak menggunakan 1,825 rekod API langsung bagi WLY01, SGR01, JHR01, SBH07 dan SWK08 untuk 2026.
- Loading bar semasa membaca atau memuat turun waktu solat.
- Mesej ralat dengan tindakan yang jelas, butiran teknikal dan butang Cuba semula. Garis masa dan countdown lama dikosongkan apabila pemuatan gagal.
- Termasuk halaman Jadual Solat dan ciri v0.3.0.

## Pemasangan

Muat turun `myAzan-0.3.1-installer.exe` untuk pemasangan atau kemas kini, atau `myAzan-0.3.1-portable.exe` untuk penggunaan tanpa pemasangan. Tutup myAzan dan myAzan Dev sebelum menjalankan versi ini. Binaan stabil menggunakan identiti aplikasi asal dan data stabil sedia ada; data dev kekal berasingan.

`SHA256SUMS.txt` disertakan untuk semakan integriti. EXE belum ditandatangani dengan sijil penerbit; Windows mungkin memaparkan amaran SmartScreen.

## Pengesahan dan binaan

Jalankan `npm test`, `npm run typecheck`, `npm run lint`, `npm run test:electron`, kemudian `npm run build -- --publish never`. Commit dan tag `v0.3.1` mesti merujuk kod binaan. Terbitkan kedua-dua EXE serta checksum sebagai GitHub Release Latest selepas semakan pakej.

Ujian Electron menggunakan database sementara. Pemasangan naik taraf pada PC lain dan Windows 10 belum diuji. Semakan API mengesahkan format tarikh, bukan pengesahan bebas terhadap ketepatan astronomi waktu solat.
