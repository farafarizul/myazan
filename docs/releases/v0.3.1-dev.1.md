# myAzan Dev 0.3.1-dev.1

Binaan ujian lokal Windows x64, 18 November 2026. Tidak diterbitkan ke GitHub Release.

## Perubahan untuk diuji

- Parser JAKIM menerima `Ogos` serta alias `Ogo`. Semua 12 bulan berjaya diproses dalam 1,825 rekod API langsung daripada WLY01, SGR01, JHR01, SBH07 dan SWK08 bagi 2026.
- Loading bar tanpa peratus rekaan semasa papan pemuka membaca cache atau memuat turun data.
- Mesej ralat yang jelas, butiran teknikal yang boleh dibuka dan butang Cuba semula. Garis masa serta countdown lama dikosongkan apabila pemuatan gagal.

## Binaan

```powershell
npm run build -- --publish never --config.appId=com.farafarizul.myazan.dev --config.productName="myAzan Dev" --config.extraMetadata.name=my-azan-dev --config.directories.output=dist-build/dev-0.3.1-dev.1
```

App ID dan nama pakej dev berasingan daripada versi umum. Installer dev tidak menggantikan pemasangan stabil; data dan tetapan dev disimpan berasingan. Tiada data pengguna disalin ke binaan. Tutup aplikasi stabil sebelum ujian untuk mengelakkan dua aplikasi memainkan audio serentak. Binaan ini belum ditandatangani dengan sijil penerbit.

## Ujian manual

1. Jalankan portable atau pasang installer dev. Semak versi `0.3.1-dev.1` di Tentang.
2. Pilih WLY01 di Tetapan dan simpan. Semak loading bar hilang selepas data tersedia.
3. Buka Jadual Solat dan semak 365 rekod 2026, termasuk Mac, Mei, Ogos, Oktober dan Disember.
4. Cuba zon yang belum dimuat turun semasa internet terputus. Semak mesej ralat, butiran teknikal dan tiada loading berterusan.
5. Sambungkan internet dan tekan Cuba semula. Semak waktu solat muncul.

Ujian automatik menggunakan database sementara. Binaan dev belum dipasang pada PC pengguna; semakan manual di atas perlu dibuat sebelum release umum seterusnya.
