# myAzan v0.3.0

Release Windows 10/11 x64 pada 18 November 2026.

## Perubahan

- Halaman Jadual Solat memaparkan semua rekod tahunan yang sudah dimuat turun untuk zon aktif, pilihan tahun tersimpan, jumlah rekod dan julat tarikh.
- Parser JAKIM menerima singkatan bulan Melayu (`Mac`, `Mei`, `Ogo`, `Okt`, `Dis`) bersama singkatan Inggeris, membaiki kegagalan muat turun selepas pertukaran zon.
- Kawalan audio idle Play, Pause, Next dan Previous, serta jadual senyap harian yang boleh ditetapkan.
- Paparan TV masjid dan pemformatan tarikh Hijri yang disertakan dalam perubahan sejak v0.2.0.

## Muat turun

- `myAzan-0.3.0-installer.exe`: pemasangan Windows.
- `myAzan-0.3.0-portable.exe`: jalankan tanpa pemasangan.
- `SHA256SUMS.txt`: checksum fail untuk semakan integriti.

Tutup myAzan sebelum menjalankan installer kemas kini. Internet diperlukan untuk memuat turun data zon yang belum tersimpan. Halaman Jadual Solat membaca data lokal sahaja; ia membantu semakan, bukan pengesahan bebas terhadap ketepatan waktu JAKIM.

## Proses release

1. Selaraskan versi dalam `package.json`, `package-lock.json` dan `src/shared/constants/index.ts`.
2. Jalankan `npm test`, `npm run typecheck`, `npm run lint` dan `npm run test:electron`.
3. Commit dan push kod, kemudian jalankan `npm run build -- --publish never` untuk installer NSIS dan portable x64.
4. Jana SHA-256 daripada kedua-dua fail dalam `dist-build/`.
5. Cipta tag `v0.3.0` pada commit binaan, push tag, dan terbitkan GitHub Release dengan kedua-dua EXE serta checksum. Tiada workflow release automatik dalam repositori semasa.

Ujian Electron menggunakan SQLite sementara dan data contoh. Pemasangan naik taraf pada PC lain, Windows 10, dan perbandingan waktu dengan API JAKIM langsung memerlukan semakan berasingan.
