# myAzan v0.3.2

Release stabil Windows x64 pada 18 November 2026.

- Logo yang hilang menggunakan logo myAzan terbina. Fail asal crop yang hilang menggunakan logo semasa.
- Audio azan dan folder zikir yang hilang menggunakan aset terbina. Audio notifikasi yang hilang menggunakan bunyi notifikasi terbina.
- QR derma, sumber QR dan latar pilihan yang hilang dikosongkan supaya tidak menghalang simpanan. Fail pilihan yang masih sah dikekalkan.
- Pemetaan default audio Subuh dan azan lain dalam bootstrap dibetulkan. Pengaktifan audio, kelantangan dan jadual tidak diubah.

Tutup myAzan dan myAzan Dev sebelum kemas kini. Pilih installer untuk pemasangan/kemas kini stabil, atau portable untuk menjalankan tanpa pemasangan. SHA256SUMS.txt disertakan. EXE belum ditandatangani dengan sijil penerbit.

Pengesahan: `npm test`, `npm run typecheck`, `npm run lint`, `npm run test:electron`, kemudian `npm run build -- --publish never`. Ujian automatik menggunakan database sementara; naik taraf pada PC lain dan Windows 10 belum diuji.
